# Hybrid Smart Navigation Plan

## Goal
Convert header nav items from pure anchors to smart navigation:
- **Projects** → navigates to dedicated `/projects` page (already exists)
- **About / Services / Contact** → scroll to section when on homepage, navigate to `/#section` when on other pages

## Current State
- `src/navigation.ts`: About, Services, Projects, Contact are all `kind: "anchor"` with `href: "#section"`
- `src/_components/layout/Header.tsx`: renders anchors as `<a href>`, routes as `<Link to>`
- `/projects` page already exists at `src/_pages/projects/index.tsx`
- `ProjectsSection` already has a "See all projects" link to `/projects`

## Changes

### 1. Update `src/navigation.ts`
- Change Projects from `{ kind: "anchor", href: "#projects" }` to `{ kind: "route", to: ROUTES.PROJECTS.LIST }`
- Keep About, Services, Contact as `kind: "anchor"` (smart behavior handled in Header, not nav data)

### 2. Update `src/_components/layout/Header.tsx`
- Import `useLocation` from `react-router-dom`
- For anchor items, determine behavior based on current path:
  - `location.pathname === "/"` → render `<a href="#section">` (native smooth scroll)
  - otherwise → render `<Link to="/#section">` (react-router navigation to homepage + hash)
- Apply same logic in both desktop nav (lines 73-81) and mobile menu (lines 124-130)

### 3. Index check
- Current nav order: About(0), Services(1), Projects(2), Learn(3), Contact(4)
- After change, order is identical — only Projects' `kind` changes
- The `i === 4` right-border rule on Contact still applies correctly

## Files to modify
1. `src/navigation.ts` — change Projects nav item
2. `src/_components/layout/Header.tsx` — add smart anchor logic

## Validation
- Run `pnpm build` to verify TypeScript compiles
- Run `pnpm dev` and test:
  - From homepage: click About/Services/Contact → smooth scrolls to section
  - From homepage: click Projects → navigates to `/projects`
  - From `/projects` page: click About → navigates to `/#about` (lands on homepage, scrolls to about)
  - Mobile menu: same behaviors
